# Mahmudi Zukri | Portfolio

Personal portfolio website for Mhd. Mahmudi Zukri Lubis, an AI Engineer and Full-Stack Developer specializing in Mobile (Flutter) and Web (Next.js) technologies.

## Tech Stack
- **Frontend**: Next.js 14, React, Tailwind CSS, Framer Motion
- **Backend & Database**: InsForge (PostgreSQL, Edge Functions)
- **Design System**: Custom Retro Pixel Theme

## Features
- **Dynamic Projects Showcase**: Fetches live portfolio data from InsForge database.
- **Admin Dashboard**: Secure backend portal to add, edit, and manage projects.
- **Interactive AI Chat**: Embedded AI widget that answers client questions using context-aware prompts.
- **Retro Aesthetic**: Distinctive pixel-art-inspired styling with sharp box shadows and earth-tone color palettes.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your `.env.local` with your InsForge credentials:
   ```env
   NEXT_PUBLIC_INSFORGE_URL=your-url
   NEXT_PUBLIC_INSFORGE_ANON_KEY=your-anon-key
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
